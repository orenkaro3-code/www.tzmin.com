# www.tzmin.com

אתר TAZMIN: שאלון (`index.html`), אזור לקוח וניהול (`portal.html`) ו-API (`api/`).

## פלאגין "מי זה" (אזור המנהל)

כשנכנסים ללקוח באזור המנהל מופיע כרטיס **מי זה · אינסטגרם ורשת**:

- **+ אזור לקוח חדש**: יוצר לקוח ומקבלים מיד קישור לצ׳אט עם כפתורי העתקה ושליחה בוואטסאפ. אפשר להכניס כבר שם את האינסטגרם של העסק.
- **אינסטגרם**: שומרים את שם המשתמש ונכנסים לפרופיל. לחיצה על "משוך נתונים" מביאה עוקבים, לייקים ותגובות ממוצעים, אחוז מעורבות, פוסטים בשבוע, היום והשעות הכי טובים, ביצועים לפי סוג (רילס, תמונה, קרוסלה) והפוסטים החזקים.
  - עובד רק על חשבון **עסקי או יוצר תוכן**.
  - צפיות בסרטונים אינסטגרם לא חושפת לאף אחד חוץ מבעל החשבון.
- **מי זה?**: מחפש ברשת את **העסק**: אתר, גוגל וביקורות, עמודים עסקיים, אזכורים ומתחרים. משלב את זה עם האינסטגרם, השאלון והצ׳אט, ומחזיר סיכום עם 5 המלצות ומקורות.
  - לא נאסף מידע פרטי על אנשים (כתובת, משפחה, חשבונות אישיים).

התוצאות נשמרות ב-Redis (`insights:<id>`). מתעדכנות רק בלחיצה, כדי לא לבזבז קריאות.

## הגדרה ב-Vercel (Settings → Environment Variables)

| משתנה | בשביל מה |
|---|---|
| `ANTHROPIC_API_KEY` | החיפוש "מי זה". מפתח מ-console.anthropic.com. בערך כמה סנטים לחיפוש. |
| `ANTHROPIC_MODEL` | לא חובה. ברירת מחדל `claude-sonnet-5-5`. |
| `IG_ACCESS_TOKEN` | טוקן ארוך-טווח של Instagram Graph API. |
| `IG_USER_ID` | ה-ID של חשבון האינסטגרם **העסקי של TAZMIN** (לא של הלקוח). |
| `IG_API_VERSION` | לא חובה. ברירת מחדל `v23.0`. |

### איך מקבלים טוקן אינסטגרם (פעם אחת)

1. **חשבון האינסטגרם של TAZMIN**: הופכים אותו לחשבון עסקי או יוצר, ומחברים אותו לעמוד פייסבוק.
2. **אפליקציה ב-Meta**: ב-developers.facebook.com יוצרים אפליקציה מסוג Business ומוסיפים את המוצר Instagram Graph API (התחברות דרך Facebook Login).
3. **טוקן קצר**: ב-Graph API Explorer בוחרים את האפליקציה ומוציאים User Token עם ההרשאות `instagram_basic`, `pages_show_list` ו-`pages_read_engagement`.
4. **טוקן ארוך**: ממירים את הטוקן לטוקן ל-60 יום בעזרת Access Token Debugger, ואז Extend.
5. **ה-IG_USER_ID**: ב-Explorer מריצים את הקריאה `me/accounts?fields=instagram_business_account`. המספר שמופיע בתוך `instagram_business_account.id` הוא ה-`IG_USER_ID`.
6. **שמירה ב-Vercel**: שמים את שני הערכים ב-Vercel ועושים Redeploy.

כשהטוקן פג, הפלאגין כותב "הטוקן פג תוקף". אז חוזרים על שלבים 3–4.
